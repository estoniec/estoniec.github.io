prandom — модуль ядра Linux — репозиторий на GitHub ↗

Написал на C модуль ядра Linux, который через /dev/gfrandom выдаёт псевдослучайные байты. Генератор использует регистр сдвига с линейной обратной связью над полем Галуа GF(2⁸). Фиксированные начальные данные позволяют воспроизводить последовательности в тестах.

  • C
  • Linux kernel
  • GF(2⁸)
